# 바카라산악회 RPG v2

## Render 설정
- Build Command: `npm install`
- Start Command: `npm start`

## GitHub 업데이트
기존 저장소의 `server.js`, `package.json`, `public/index.html`을 이 프로젝트 파일로 교체/추가하세요. 기존 최상위 `index.html`은 사용하지 않으므로 삭제해도 됩니다.

## 포함 기능
- 직업 선택: 고회장 전사 / 신선생 궁수 / 낙엽이 마법사 / 새싹이 보조힐러
- 직업별 HP, 공격력, 방어력, 사거리, 스킬
- 몬스터 추적 및 반격, 플레이어 사망 후 마을 부활
- 골드, 경험치, 레벨업, 랜덤 아이템 드롭
- 가방, 장비 장착, 강화 주문서, 회복 물약
- 모바일 조이스틱과 공격/스킬 버튼

## 중요
v2 프로토타입입니다. 캐릭터/인벤토리는 현재 메모리 기반이므로 서버 재시작 시 초기화됩니다. 실서비스 전 계정 인증, DB 영구 저장, 치트 방지, 서버측 이동 검증, 직업 밸런스/힐러 스킬 강화가 필요합니다.
